# REDUCEAM

Kompressor is a free, fast, optional login files editing toolbox on the web + a versioned HTTP API for developers.

* Compress images to a custom quality level.
- Convert between formats (png -> jpg, mp4 -> mkv, pdf -> docx)
- Read image/video metadata (dimensions, format, EXIF, color mode, file size)
- real time editor for markdown & html file
- **ENV STORAGE WITH ENCRPYTION SIMPLE BUT DIFFICULT TO DECODE - JUNGLE LANGUAGE**
- Embed a password-protected message inside an image, and decode it later with that password
